## Locked decisions (do not relitigate)

- **Design is LOCKED** — machine HMI, amber primary, state by treatment not hue (`docs/pd-studio-design.md`). Redesign the *product*, never the *design*.
- Process line: INPUT → BRAND → **ADS** (renamed from MARKET; campaign/performance only) → SOCIAL (owns ALL creative incl. video) → PLATFORM (one button).
- **Imagery/video = Higgsfield's lane, never Claude's** (Claude does text/structure only).
- Output stores are **agent-first**: SSR HTML + JSON-LD + feeds; no marketing hero. Agents don't execute JS; llms.txt is a bonus, never the channel.
- **Review-before-publish framing** (post-Icon.com collapse): the machine drafts and checks against the brain; the human approves. No full-autonomy claims.
- MERIDIAN exists ONLY as: first preset order, line-failure fallback (with banner), and labeled demo API sample. Any other MERIDIAN sighting is a bug.

## Architecture map

- **The machine:** `src/app/studio/page.tsx` (all modules + AdModal). Fab page: `src/app/studio/site/page.tsx`.
- **AI routes (all Claude sonnet-5, stateless):** `/api/studio/brandkit` (kit+campaign), `/api/studio/storefront` (catalog+manifest), `/api/studio/copy` (brain-steered post rewrite).
- **Published store:** `/store/[slug]` + `/p/[sku]` (server components) · feed pack routes beside them · report at `/api/store/[slug]/report` · publish at `/api/store/publish`.
- **Persistence (file-based, gitignored `.data/`, swap-to-Supabase seams):** `src/lib/studio/storeRepo.ts`, `src/lib/studio/brainRepo.ts`. Shared brain rules: `src/lib/studio/brain.ts`. Storefront builders: `src/lib/studio/aiStorefront.ts`.
- **Hand-offs:** studio → site: localStorage `pdr-site-kit` = `{kit, ts}` (30-min TTL, no fallback); site → studio: `pdr-last-store` slug.
- **Gotchas:** Lenis must stay disabled for `/studio*` (`src/components/v2/smooth-scroll.tsx`); "frozen" tickers in dev = stale Fast Refresh — hard reload. Middleware (`src/middleware.ts`) skips `/studio*`, `/store/*` and their APIs entirely, skips anonymous requests (no sb- cookie), and its Supabase auth refresh is try/caught — a paused Supabase project must never slow the machine again.
